# Recipes

Use `search_recipes` when the user needs recipe ideas based on ingredients,
cuisine, category, or search terms. Use `get_recipe` when the user provides a
specific recipe URL.

Summarize results concisely and state only data returned by the MCP server.
Ask follow-up questions when important requirements, such as dietary needs,
allergies, or available ingredients, are missing.
